# ChatNova - Your Personal AI Assistant

ChatNova is a personal AI assistant web application.

## Project Vision

A professional, secure and responsive AI chatbot with persistent chat history and AI-powered document question answering.

ChatNova will integrate an existing Large Language Model API. It will not train a foundation model from scratch.

## Technology Stack

### Frontend
- React.js
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React

### Backend
- Python
- FastAPI
- Pydantic
- SQLAlchemy

### Database and Authentication
- Supabase PostgreSQL
- Supabase Auth
- Alembic

### AI and Document Intelligence
- LLM API
- Server-Sent Events
- Retrieval-Augmented Generation
- Embeddings and pgvector

### Testing
- Pytest
- Vitest
- Playwright
